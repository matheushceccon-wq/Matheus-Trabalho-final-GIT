# Mundo Esporte

O Mundo Esporte é um projeto de site voltado para a apresentação de produtos esportivos. O projeto foi desenvolvido para fins acadêmicos, utilizando HTML5 e CSS3, com o objetivo de criar uma página organizada, simples e fácil de navegar.

## Sobre o projeto

O site apresenta uma estrutura com cabeçalho, menu de navegação, área de produtos e rodapé. No menu estão disponíveis opções como Início, Produtos, Contato, Notícias, Sobre, Saiba Mais, Perfil e Configurações.

Na área principal são apresentados produtos esportivos, contendo imagem, nome, descrição, preço e botão de compra. Entre os produtos estão chuteiras e uma bola de futebol.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

**HTML5:** responsável pela estrutura e organização dos elementos da página.

**CSS3:** responsável pela aparência, cores, espaçamentos, alinhamentos e organização visual do site.
